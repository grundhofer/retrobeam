Ohne Layer gewinnen diese Regeln aus `SB/css/sebaro.css` gegen jede Tailwind-Regel in `@layer`, unabhängig von der Spezifität:

- `button, input, select, textarea { font: inherit; letter-spacing: inherit; color: inherit; }` (`:40`). **Größe und Farbe springen:** Jedes `text-sm` auf einer Taste und jedes `text-white` auf einer Teal-Taste fällt auf die geerbten Werte zurück. Dunkle Schrift auf Teal ist ein Kontrastproblem.

- `p { max-inline-size: … }` (`:60`).
- `a { color: var(--sb-color-text); text-decoration: underline … }` (`:63-64`). CTA-Links verlieren ihre weiße Schrift und bekommen den Unterstrich.
- `:focus-visible` (`:71`); `body.sb-page` (`:35`).
