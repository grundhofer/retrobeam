# 06 — License, ownership and trademark

Status: 2026-08-06, updated 2026-09-29 (the repository is public). This file records the licensing
decision, what is already implemented, and what is still open. It is not legal advice — the items under
[Open before launch](#open-before-launch) need a lawyer.

## The decision

**AGPL-3.0-or-later**, sole rights holder **Sebastian Grundhöfer**, CLA required for every external
contribution.

Rationale, in order of weight:

1. **It keeps monetisation open.** The rights holder is not bound by the licence they grant. RetroBeam
   can be sold as a hosted service and simultaneously offered under a paid commercial exception
   licence to companies that cannot adopt copyleft. This is the Sentry/GitLab pattern.
2. **It is the strongest defence against a closed-SaaS clone.** AGPL § 13 forces anyone who runs a
   modified RetroBeam over a network to offer their users the source. A competitor either publishes
   their work or buys an exception licence. A permissive licence (MIT, as Scrumlr and Reflect use)
   gives that away for free.
3. **It matches the positioning.** `01-product-spec.md` sells "genuinely free" against a market that
   has retreated from free. A source-available licence (BSL, SSPL, FSL) would contradict the pitch.

**Not planned:** a later relicense away from copyleft. Published versions stay AGPL forever and the
community can fork the last free commit — HashiCorp → OpenTofu is the cautionary case. The revenue
model must work _with_ the AGPL, not around it.

**Not planned:** No mandatory or default-on telemetry in the AGPL edition. See
[Why there is no phone-home / telemetry](#why-there-is-no-phone-home--telemetry).

### What the model can and cannot be

| Viable                                            | Blocked by AGPL                                                                         |
| ------------------------------------------------- | --------------------------------------------------------------------------------------- |
| Hosted instance (free tier + paid team tier)      | Classic open core — a proprietary "Pro" module in the same process is a derivative work |
| Commercial exception licence (per § 2 of the CLA) | Shipping a closed plugin API that only paid builds unlock                               |
| Support, consulting, managed/self-host assistance | Withholding source from users of the hosted instance                                    |
| Trademark licensing (once registered)             | —                                                                                       |

### The in-app notices (AGPL § 5(d) and § 13)

`LegalFooter` renders on all three screens a participant actually uses — the home page, the join gate
and the board — and carries the four Appropriate Legal Notices that § 0 defines and § 5(d) makes
mandatory (copyright, the licence recipients may convey under, the warranty disclaimer, how to view
the licence) plus the § 13 source offer.

The source link points at the **exact running commit**. The SHA is injected at build time via
`VITE_COMMIT_SHA`, set in both deploy paths:

- `.github/workflows/deploy.yml` — `${{ github.sha }}` for production, the PR head SHA for previews
- `apps/web/package.json` `deploy` script — `$(git rev-parse HEAD)` for a local `wrangler deploy`

A build without that variable degrades to the default branch instead of the exact version. That is
correct for `pnpm dev` and for tests, but **a deployed build must always carry it** — verified by
building both ways.

The repository `grundhofer/retrobeam` is public, so both links resolve for everyone and the § 13
source offer is actually discharged (verified 2026-09-29: the GitHub API reports `private: false` and
the commit link of the running build answers 200). It must stay public, or the source must be served
some other way — taking it private again would break the promise the footer makes.

### Why there is no phone-home / telemetry

Decided 2026-09-30: a self-hosted instance sends nothing to the author — no telemetry, no licence
check, no update ping. The README says so in those words. The question was whether one could tell who
runs RetroBeam and where; the answer is that a phone-home would not tell, and would cost more than it
earns.

1. **It cannot be enforced.** AGPL § 2 lets anyone run the unmodified program without restriction; § 13
   only applies once the program is modified. A duty to report usage would be a "further restriction"
   (§ 7, last paragraphs, and § 10) that every recipient may simply remove. Whoever breaches § 13 has
   changed the code anyway and deletes the call with one line. It would only catch the honest users.
2. **It cannot measure "who and where".** Self-hosting is documented only on Cloudflare Workers, so a
   ping arrives from Cloudflare IPs and reveals neither the organisation nor the location.
3. **It contradicts the product's own promise.** The landing page says "kein Tracking" and the privacy
   notice describes an instance that talks to no one but its sub-processors.
4. **It creates legal exposure for the author and for adopters.** The author would likely become a
   joint controller for other people's instances (Art. 26 GDPR, _Fashion ID_). A ping from the browser
   falls under § 25 TDDDG and needs consent, which ends the banner-free basis. For a works council it
   is a new processing that an existing Betriebsvereinbarung probably does not cover — the opposite of
   the § 87 BetrVG story in `05-privacy-gdpr.md`.
5. **The community precedent is against it.** GitLab withdrew its telemetry plan in 2019 after
   backlash; Go made its toolchain telemetry opt-in in 2023; Audacity's telemetry plan in 2021 produced
   the Tenacity fork.

What is done instead:

- **The § 13 source offer** in `LegalFooter` — every modified network deployment has to publish its
  source, which is where adopters become visible if they change anything.
- **The fork guard.** `pnpm check:legal` runs before every deploy (both jobs in
  `.github/workflows/deploy.yml` and the `deploy` script in `apps/web/package.json`). Besides
  bracketed placeholders, it compares the production route in `apps/worker/wrangler.jsonc` with
  `INSTANCE_HOST` in `apps/web/src/content/operator.ts`. A clone deployed to any other host stops,
  naming each file to change, until it carries its own operator data, its own `REPO_URL` (so the
  § 13 link reaches the source of _its_ build), its own `WORKERS_DEV_HOST` and its own host in
  `index.html`, `robots.txt`, `sitemap.xml`, the imprint and the privacy notice. Cloudflare does
  _not_ stop a clone that keeps the retrobeam.de route: `wrangler deploy` uploads the Worker and
  switches on its workers.dev origin before the custom domain fails on a zone that is not theirs, so
  retrobeam.de's imprint would already be live. The guard therefore also checks which repository is
  being deployed — `GITHUB_REPOSITORY` in Actions, the `origin` remote for the local deploy script —
  and treats anything other than grundhofer/retrobeam as a clone. The gap left is a plain
  `git clone` of upstream deployed unchanged from the command line: it is indistinguishable from
  retrobeam.de's own checkout without a network call, which is why the README says to fork first.
  The guard is a courtesy, not a lock — a forker can delete it — but a fork does not ship someone
  else's imprint by accident.
- **The trademark** (below) — the lever against a clone that trades on the name.
- **Voluntary channels** — an `ADOPTERS.md` or a "Who uses RetroBeam?" discussion, plus GitHub
  traffic, stars, forks and CLA signatures.
- **Own-instance metrics** from the Cloudflare dashboard only (Worker requests, Durable Object calls
  and storage). They cost nothing, need no code and change nothing in the privacy notice.

   - § 31a UrhG requires _Schriftform_ (wet signature) to grant rights for **unknown** future types of

     types of use known at the time of contribution. Confirm this limitation is acceptable, or decide

     Ask whether the exclusive grant in § 2 survives that review, and whether § 7's reversion clause

4. **Impressum and Datenschutzerklärung** — built 2026-09-11 as `/impressum` and `/datenschutz`

   - The landing page's "not a commercial service" line describes the operation of retrobeam.de
     today, deliberately not the licence and not the future — so it does not contradict the

   no forks.

   > **DRAFT — not in force.** Additional terms under section 7 of the GNU Affero General Public
   > License, version 3, for RetroBeam:
   >
   > (b) Pursuant to § 7(b), you must preserve the author attribution "© Sebastian Grundhöfer" and the

## Dependency policy

**The production closure must stay permissive (MIT / BSD / ISC / Apache-2.0).** A single copyleft
dependency in the core would make the commercial exception licence unsellable, because the rights
holder cannot grant an exception to code they do not own.

Audit of 2026-08-06 — 21 third-party packages in the production closure, **zero copyleft**:

| Licence    | Packages                                                                                                                                                                                                                                                                                               |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| MIT        | `@babel/runtime`, `@types/react`, `cookie`, `csstype`, `event-target-polyfill`, `hono`, `html-parse-stringify`, `i18next`, `partysocket`, `react`, `react-dom`, `react-i18next`, `react-router`, `scheduler`, `set-cookie-parser`, `uqr`, `use-sync-external-store`, `void-elements`, `zod`, `zustand` |
| ISC        | `canvas-confetti`                                                                                                                                                                                                                                                                                      |
| Apache-2.0 | `typescript`                                                                                                                                                                                                                                                                                           |

Added since: `uqr` (MIT, 2026-09-29) — the QR code for the team link in the lobby and the invite
panel. Zero dependencies, encoded in the browser, never fetched from a QR service; it sits in its own
lazily loaded chunk (`apps/web/src/lib/qr.ts`), so the entry bundle does not carry it.

Apache-2.0 is one-way compatible: it may be combined into AGPLv3 work, but not the reverse. That is
fine here and does not affect the exception licence, since Apache-2.0 permits proprietary
sublicensing.

Note the planned `emoji-picker-element` (`01-product-spec.md`) is Apache-2.0 — acceptable. Re-run the
audit before each release:

```sh
pnpm -r list --prod --depth Infinity --json   # then check each package's license field
```

## Trademark "RetroBeam"

### Why the project was renamed

The product was called **Retropolis** until 2026-09-09. That name was **already in active commercial
use** by at least three unrelated software products — _The Secret of Retropolis_ and _Retropolis 2:
Never Say Goodbye_ (VR adventure games by Peanut Button Studio, on Steam and Meta Quest), and
_Retropolis – Rule the Streets_ (a mobile strategy game by VoidForge, `retropolisgame.com`). Those
sit in **Nice class 9 (software)** and class 41 (entertainment), and a retro tool needs class 9 and
class 42 (SaaS): class 9 overlapped literally. Combined with `retropolis.de` being taken, the name
was replaced rather than defended.

### What was found for "RetroBeam"

A name search on 2026-09-09 returned **no product, company or project called RetroBeam** — not in the
retrospective/agile category, not in software generally, and not on GitHub. That is the reason it was
chosen over the alternatives, several of which failed exactly here: `RetroSpark` is itself a
real-time agile retrospective tool, `RetroLeap` is a LeapFrog emulation firmware with several GitHub
forks, `RetroLift` is a Photoshop product, and `Everyturn` is a UK mental-health charity.

**A clean name search is still not a clearance search**, and the class-9 exposure that applied to the
old name applies to any name: the risk was reduced, not removed.

**This is not a clearance search.** The public trademark registers (DPMAregister, TMview, EUIPO
eSearch, WIPO Global Brand Database) are not machine-readable and Justia blocks automated access, so
whether anyone holds a _registered_ mark on "RetroBeam" is **unverified**. Do not treat the absence
of a finding as a clean result — run the register search below before printing anything.

### What to do, in order

1. **Free self-search first**, before spending anything:
   - DPMAregister — <https://register.dpma.de> (German marks)
   - TMview — <https://www.tmdn.org/tmview/> (DE + EU + international in one query)
   - EUIPO eSearch — <https://www.euipo.europa.eu/en/search>
   - WIPO Global Brand Database — <https://branddb.wipo.int>

   Search classes 9, 41 and 42, and search for similar marks, not just the exact string —
   Verwechslungsgefahr covers similarity, not identity.

2. **If the register looks clear, still get a professional Recherche** (roughly €300–800) before
   filing. Self-searches routinely miss phonetically or conceptually similar marks, and filing into a
   conflict costs the fee plus an Abmahnung.

3. **File.** Verified fees as of August 2026:

   | Office     | Scope   | Basic fee                            | Extra classes                      | Term     |
   | ---------- | ------- | ------------------------------------ | ---------------------------------- | -------- |
   | DPMA (DE)  | Germany | **€290** electronic, up to 3 classes | €100 per further class             | 10 years |
   | EUIPO (EU) | All EU  | **€850** electronic, 1 class         | €50 for the 2nd, €150 each further | 10 years |

   Recommendation: **DPMA first** (classes 9 + 42, €290 total). The audience per
   `03-competitive-analysis.md` is German-speaking teams that want EU residency, so German protection
   covers the actual market at a third of the EU cost. Escalate to EUIPO only if the product goes
   international — a German registration gives a six-month priority window for that.

4. **If the name turns out to be blocked**, decide as early as possible. The repository and
   retrobeam.de are already public, so a rename is no longer free — but it only gets more expensive
   with every user and every fork (none yet on 2026-09-29).

### Even without registration

Using "RetroBeam" commercially in Germany creates an **Unternehmenskennzeichen** under § 5 MarkenG,
which gives limited protection from first use. That is weaker than a registered mark — it does not
survive a third party registering the name — but it means the name is not entirely unprotected in the
window before filing.

The trademark is worth more than the licence here: it is the one asset a fork cannot take. Anyone may
fork the AGPL code, but nobody may call their fork RetroBeam. That is exactly how Grafana, Redis and
WordPress protect themselves.

## Why the CLA matters more than it looks

The moment an external pull request is merged **without** a signed CLA, that contributor becomes a
joint rights holder in their portion. From then on:

- no commercial exception licence can be sold that includes their code,
- no relicensing decision can be made unilaterally,
- enforcement against an infringer needs their cooperation.

There is no retroactive fix short of tracking every contributor down or ripping their code out. The
CLA was set up while the repository was still private and had no external contributors, which was the
cheapest it would ever be. The repository is public now; on 2026-09-29 it still had no contributors
besides the owner and Dependabot, so the CLA gate has not yet had to hold.
